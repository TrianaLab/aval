A contract can depend on other contracts in the same repository. The optional `scope.contracts` list takes paths to other `aval.yaml` files, relative to the contract (`../backend/aval.yaml`). Each referenced contract is fingerprinted from its own directory and scope, and its fingerprint goes into the manifest as a `contract <path> <name> <fingerprint>` line, transitively: a change inside a referenced contract's scope makes the dependent miss and run, a change outside it does not. References must stay inside the git working tree of the contract (the nearest directory with a `.git` entry); a missing, invalid, symlinked or cyclic reference, or more than 8 levels or 64 contracts, fails the fingerprint, so the test runs. A referenced contract's mutable references block the dependent's reuse unless the referenced contract's own `scope.allowMutable` accepts them. `aval run --explain` prints the dependency tree after the manifest. Format changes, additive: the contract field within `aval.trianalab.io/v1` (older binaries reject contracts that use it), and the `contract <path>` manifest lines within `aval-fingerprint/v1`, which only contracts with the field have; every other manifest is unchanged. Guide: "Depend on another part of the repo".
