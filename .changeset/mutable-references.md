"aval": minor

Aval detects mutable references in a test's inputs and refuses to reuse them. A static, offline scanner reads the files in the contract scope and `runner.command`, one detector per ecosystem: container images without a digest (Compose and Kubernetes `image:`, Dockerfile `FROM` and `COPY --from`, `docker run` and `podman run`, compose files the command uses but the scope does not hold), Go (`go.mod` without `go.sum`, `go install pkg@latest`), npm, yarn, pnpm and bun (`package.json` without a lockfile, unpinned `npm i` and `npx`), Python (unpinned `requirements*.txt` entries, missing hashes, Poetry and Pipenv without a lockfile, unpinned `pip install`), Rust (`Cargo.toml` without `Cargo.lock`), Java (Maven and Gradle `SNAPSHOT`, `LATEST`, `RELEASE`, dynamic versions and ranges), Ruby (`Gemfile` without `Gemfile.lock`), PHP (`composer.json` without `composer.lock`), OS packages (`apt-get install` and `apk add` without versions), remote scripts (`curl … | sh`, remote `ADD` without `--checksum`) and git (`git clone` without a commit, submodules that track a branch). For `hermetic` and `controlled-environment` contracts any unacknowledged finding makes the lookup a `miss` (exit 4 for `verify`) whose reason lists each reference, the test runs, and `run --push` and `push` do not publish (exit 1). `external-dependencies` contracts get the findings as information; `non-deterministic` is unchanged. `aval run` prints each finding as a `mutable:` line (`--fingerprint-only` prints them on stderr). Contract format change, additive within `aval.trianalab.io/v1`: the optional `scope.allowMutable` list (`ref` and `reason`) acknowledges a reference by the exact text Aval reports. It is part of the contract hash; contracts without it keep their fingerprint, and the manifest stays `aval-fingerprint/v1`. Older `aval` binaries reject contracts that use the new field. A contract whose scope holds a mutable reference that earlier versions reused now misses until the reference is pinned or acknowledged. Guide: "Pin your dependencies" (`docs/pinning.md`).
