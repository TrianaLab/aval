Aval resolves declared artifacts to immutable ids at fingerprint time. The optional `scope.resolve` list takes `kind: reference` entries for container images (`image`, tag to manifest or index digest), npm, PyPI, Go modules (through the module proxy, `h1:` hash), Maven, crates.io, RubyGems, git (ref to commit with `git ls-remote`) and plain URLs (sha256 of the download, up to 256 MiB). Each resolves a tag, a version range or a branch to its digest, checksum or commit, which goes into the manifest as a `resolve <kind> <reference> <version> <id>` line: a repushed tag, a new release inside a range or a moved branch changes the fingerprint. Resolution is opt-in and stateless, bounded by a 2-minute deadline; a reference that cannot be resolved fails the fingerprint, so nothing is looked up, the test runs and nothing is published, and the reason names the reference. `aval run --explain` prints the time each lookup took on stderr. `scope.resolve` never clears a finding of the mutable-reference scanner: it makes a move change the fingerprint, and the reference still blocks reuse until it is pinned in place or accepted with `scope.allowMutable`. `scope.resolve` binds the named artifact, not its transitive dependencies. Registries come from `$npm_config_registry`, `$GOPROXY`, `$AVAL_PYPI_URL`, `$AVAL_MAVEN_URL`, `$AVAL_CRATES_INDEX` and `$AVAL_RUBYGEMS_URL`; credentials from the Docker config, `~/.npmrc` tokens, `~/.netrc` machine entries and git, sent only over https or to a loopback host. Format changes, additive: the contract field within `aval.trianalab.io/v1` (older binaries reject contracts that use it), and the `resolve` manifest lines within `aval-fingerprint/v1`, which only contracts with the field have; every other manifest is unchanged. Guide: "Resolve references" (`docs/resolve/`).
