// how it works

Three steps. No server to run.

01 · declare

List the inputs

Write the files and tools your test reads in aval.yaml. Aval hashes them into one fingerprint.

02 · sign

Run once, sign the result

On a miss the test runs. With --push, Aval signs the result and stores it in your OCI registry.

03 · reuse

Verify, then skip

Same fingerprint, trusted signer: the test is skipped. Anything else: the test runs.

A result that fails verification is a security event, never a quiet miss.
